# NewsAggregator

## EN

This is a small app for collecting news headlines from the News API. It runs on
Python and uses FastAPI for its endpoints. The data is sourced from the News
API and to use this app you must create an API key from their
[website](https://newsapi.org/).

There is a small script to run Docker on your local machine called `run.sh`,
considering Docker is installed and running in your system the script will
start the backend and make it avalilable on your `localhost` with port `8000`.

## BR

Este é um pequeno app que coleta dados de noticiários da News API. Para usar o
app você precisa criar uma chave de API no site do [News
API](https://newsapi.org/). Para rodar o contêiner utilize o script
`run.sh` que disponibilizará o app no seu localhost.
